# Animalese Prototype Voice Samples

These files are copied from the `animalese-tts` demo at commit
`befec7bb8545a7ecc2b72164cf9d04b6359a5f3f`:

- <https://github.com/izure1/animalese-tts/tree/befec7bb8545a7ecc2b72164cf9d04b6359a5f3f/docs/sounds>

The application currently uses `english-sprite`, `japanese-sprite`, and
`korean-sprite` as temporary prototype assets. The upstream repository is MIT
licensed, but the audio samples' original provenance and release suitability
must be verified separately before Pets-Driven ships them in a production
release. Replace the samples if that verification is not conclusive.
