# Pet Surface Uses Individual Windows

Accepted. Visible pets live in individual desktop overlay windows instead of one large transparent surface. The platform only toggles click pass-through for a whole window, not for part of one, so a single full-screen surface forces an all-or-nothing choice: leave it opaque to clicks and block every app behind it, or make it click-through and lose the ability to grab and drag a pet (direct manipulation). Sizing each pet's window to its sprite sidesteps this — the window itself becomes the pet's hit area, so clicks land on the pet while the surrounding desktop stays fully interactive, with no per-region hit-testing workaround. The management UI remains a normal app window, and each pet window stays small enough for users to keep working around it while still supporting direct manipulation, context menus, and attention overlays.
