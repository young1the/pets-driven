# Single Simulation World Spans the Virtual Desktop

Accepted. Even though visible pets live in individual Pet Windows (ADR 0001), there is one Simulation World whose coordinate space is a single continuous plane spanning the entire virtual desktop across all monitors. Each pet has a world position; each Pet Window is positioned by projecting that world position onto virtual-desktop screen coordinates. Pets approach, contact, and react to each other inside this one world regardless of which monitor their windows appear on. We rejected one world per monitor because it would split the shared simulation and stop cross-monitor pets from meeting, and we rejected restricting the world to a single monitor because pets could then be trapped on a monitor the user is not looking at. The trade-off is that monitor bezels and gaps are not modeled in the MVP — the world treats the virtual desktop as one uninterrupted surface — and OS windows never physically collide; collision and contact are computed only in the Simulation World.
